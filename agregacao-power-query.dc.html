Agregação no Power Query

Os arquivos da extração vêm no grão de SKU × dia × cliente e somam 360 MB — o navegador não processa isso. Esta etapa soma o SKU e o dia no Excel e entrega sete CSVs pequenos no grão que o Atualizador espera.

Hoje
360 MB
SKU × dia × cliente, seis arquivos de entrada
Depois
~2 MB
BU × marca × cliente × canal
O que soma
SKU + dia
o boletim nunca abre nesse nível
O dia sobrevive
curva.csv
dia × BU × canal, ~200 linhas
A troca central. Sem o dia dentro de vendas.csv, o Atualizador não consegue mais deduzir a data de corte nem os dias úteis a partir da base. Por isso o meta.csv deixa de ser opcional: ele passa a carregar essas quatro informações. São quatro linhas digitadas uma vez por dia — bem mais barato que carregar 300 mil linhas de data.

1. Preparar a pasta de trabalho

Abra uma pasta de trabalho nova do Excel e salve como Agregador Boletim.xlsx na mesma pasta dos arquivos da extração. Em Dados → Obter Dados → Consulta em Branco, abra o Editor Avançado e cole o código de cada consulta abaixo, uma consulta por bloco.

A primeira consulta é um parâmetro com o caminho da pasta. Crie-a antes das outras: todas dependem dela.

2. Função de leitura

Uma função só para abrir qualquer um dos arquivos e padronizar os nomes das colunas. É o único lugar que você ajusta se a extração mudar de cabeçalho — as consultas seguintes só consomem o resultado dela.

Consulta: fnLerconfira o bloco Renomear
let
    fn = (arquivo as text) as table =>
let
    Fonte = Csv.Document(
        File.Contents(Pasta & "\" & arquivo),
        [Delimiter = ";", Encoding = 1252, QuoteStyle = QuoteStyle.Csv]
    ),
    Cabecalho = Table.PromoteHeaders(Fonte, [PromoteAllScalars = true]),

    // Nomes da extração à esquerda, nomes do boletim à direita.
    // MissingField.Ignore deixa passar arquivo que não tem alguma delas.
    Renomear = Table.RenameColumns(Cabecalho, {
        {"Data",              "DATA"},
        {"Dt Venda",          "DATA"},
        {"BU",                "BU"},
        {"Unidade Negocio",   "BU"},
        {"Marca",             "MARCA"},
        {"Canal",             "CANAL"},
        {"Cliente",           "CLIENTE"},
        {"Rede",              "CLIENTE"},
        {"Valor",             "VALOR"},
        {"Valor Liquido",     "VALOR"}
    }, MissingField.Ignore),

    Chaves = List.Intersect({ {"DATA","BU","MARCA","CANAL","CLIENTE"}, Table.ColumnNames(Renomear) }),
    Tipos = Table.TransformColumnTypes(
        Renomear,
        List.Transform(Chaves, each {_, type text}) & { {"VALOR", type number} }
    ),
    Limpo = Table.TransformColumns(
        Tipos,
        List.Transform(Chaves, each {_, each Text.Upper(Text.Trim(_ ?? "")), type text})
    ),
    ValorZero = Table.ReplaceValue(Limpo, null, 0, Replacer.ReplaceValue, {"VALOR"})
in
    ValorZero
in
    fn

Se os arquivos estiverem em UTF-8 em vez de ANSI, troque Encoding = 1252 por 65001. Se o separador for vírgula, troque Delimiter. Os acentos na prévia dizem qual está certo.

3. As cinco tabelas agregadas

Todas seguem o mesmo desenho: ler, agrupar por BU × marca × canal × cliente, somar. O SKU e o dia desaparecem no agrupamento — é aí que os 360 MB viram 2 MB. Ajuste só os nomes de arquivo na primeira linha de cada uma.

Consulta: vendas
let
    Fonte = fnLer("Vendas.csv"),
    Agrupado = Table.Group(
        Fonte,
        {"BU", "MARCA", "CANAL", "CLIENTE"},
        { {"REAL", each List.Sum([VALOR]), type number} }
    ),
    Arredondado = Table.TransformColumns(Agrupado, { {"REAL", each Number.Round(_, 2), type number} }),
    SemZero = Table.SelectRows(Arredondado, each [REAL] <> 0)
in
    SemZero
Consulta: vendas-aarecortado no mesmo dia do mês
let
    Fonte = fnLer("Vendas AA.csv"),

    // O ano anterior entra inteiro: o boletim compara o mês cheio de AA
    // com a projeção do mês cheio atual. O recorte MTD sai da curva.
    Agrupado = Table.Group(
        Fonte,
        {"BU", "MARCA", "CANAL", "CLIENTE"},
        { {"REAL", each List.Sum([VALOR]), type number} }
    ),
    Arredondado = Table.TransformColumns(Agrupado, { {"REAL", each Number.Round(_, 2), type number} }),
    SemZero = Table.SelectRows(Arredondado, each [REAL] <> 0)
in
    SemZero
Consultas: projecao-atual · projecao-inicial · orcamentotrês cópias, muda o arquivo e o nome da coluna
// projecao-atual
let
    Fonte = fnLer("Projeções_atual.csv"),
    Agrupado = Table.Group(Fonte, {"BU", "MARCA", "CANAL", "CLIENTE"},
        { {"PROJ_ATUAL", each List.Sum([VALOR]), type number} }),
    SemZero = Table.SelectRows(Agrupado, each [PROJ_ATUAL] <> 0)
in
    SemZero

// projecao-inicial  →  arquivo "Projeções_inicial_rateada.csv", coluna PROJ_INICIAL
// orcamento         →  arquivo "Orçamento.csv",                 coluna ORCAMENTO
Consulta: curvaa única que guarda o dia
let
    // Dia × BU × canal, sem marca e sem cliente: umas 200 linhas.
    Atual = Table.Group(
        Table.AddColumn(fnLer("Vendas.csv"), "DIA", each Date.Day(Date.From([DATA])), Int64.Type),
        {"DIA", "BU", "CANAL"},
        { {"REAL", each List.Sum([VALOR]), type number} }
    ),
    Anterior = Table.Group(
        Table.AddColumn(fnLer("Vendas AA.csv"), "DIA", each Date.Day(Date.From([DATA])), Int64.Type),
        {"DIA", "BU", "CANAL"},
        { {"REALAA", each List.Sum([VALOR]), type number} }
    ),
    Junto = Table.NestedJoin(Anterior, {"DIA","BU","CANAL"}, Atual, {"DIA","BU","CANAL"}, "a", JoinKind.FullOuter),
    Expandido = Table.ExpandTableColumn(Junto, "a", {"REAL"}),
    Ordenado = Table.Sort(Expandido, { {"DIA", Order.Ascending}, {"BU", Order.Ascending} }),
    Zeros = Table.ReplaceValue(Ordenado, null, 0, Replacer.ReplaceValue, {"REAL", "REALAA"})
in
    Zeros

Se a coluna DATA vier como texto dd/mm/aaaa, troque Date.From([DATA]) por Date.FromText([DATA], [Format="dd/MM/yyyy"]).

4. O meta.csv

Quatro linhas que substituem tudo que antes era deduzido das datas. Digite numa aba comum do Excel — não precisa de consulta — e salve como CSV.

diasUteis15dias úteis realizados no mês

divisor1000000valores em R$ → R$ milhões

5. Exportar os CSVs

Cada consulta vai para uma aba: Fechar e Carregar Para → Tabela → Nova Planilha. Depois, com a aba ativa, Arquivo → Salvar Como → CSV UTF-8 (delimitado por vírgula), uma aba por vez. O Excel salva só a aba ativa e avisa isso — é o comportamento esperado.
